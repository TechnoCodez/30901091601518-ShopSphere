# Cloud Service Classification

1. **Frontend (React on Vercel)**
   * **Classification:** Platform as a Service (PaaS)
   * **Justification:** Vercel manages the build step, static asset hosting, and global CDN routing without requiring manual server provisioning.

2. **Backend Monolith (Express on Vercel)**
   * **Classification:** Platform as a Service (PaaS)
   * **Justification:** Executes Node.js API logic in a fully managed serverless runtime environment, auto-scaling without virtual machine management.

3. **Database (Supabase PostgreSQL)**
   * **Classification:** Database as a Service (DBaaS)
   * **Justification:** Provides a fully hosted PostgreSQL database with managed backups, connection pooling, and automated scaling.
